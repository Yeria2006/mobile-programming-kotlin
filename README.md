# Mobile Programming — Kotlin

Kumpulan program Kotlin dari mata kuliah Mobile Programming, Program Studi IT and Big Data Analytics — Calvin Institute of Technology.

Setiap program dijalankan di [Kotlin Playground](https://play.kotlinlang.org).

## Daftar proyek

| Proyek | Deskripsi | Status |
|---|---|---|
| [Proyek 1](./proyek-1-sistem-nilai) | Sistem Nilai Mahasiswa — mengolah data nilai, menghitung rata-rata dan status kelulusan, menentukan grade | Selesai |
| Proyek 2 | Kasir Toko Sederhana | Belum dikerjakan |

## Cara menjalankan

1. Buka folder proyek yang mau dicek.
2. Copy isi file `.kt` ke [play.kotlinlang.org](https://play.kotlinlang.org).
3. Klik Run.

## Struktur tiap folder proyek

```
proyek-x-nama-program/
├── NamaProgram.kt   # kode program
├── output.png        # screenshot hasil run
└── README.md          # ringkasan proyek
```
